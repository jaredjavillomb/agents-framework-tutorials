Setup guide · no coding needed

Run three AI agent tutorials on your computer

This project teaches how AI "agents" are built, using three popular toolkits: LangGraph, CrewAI and Strands Agents. Everything runs on your own Mac or Windows PC with a free AI model. There is no API key and nothing to pay for, and no account to create. This page walks you through the setup one step at a time. You will copy and paste a few commands; you do not need to understand them.

First, check your computer

The AI model runs on your own computer, so how much memory (RAM) it has decides which size of model to use. Find it like this:

  • Open the Apple menu (top left of the screen) and choose About This Mac.
  • Chip says Apple M1, M2, M3 or M4 on newer Macs, or Intel on older ones.
  • Memory says how much memory it has, for example 16 GB.
  • For disk space, open Apple menu › System Settings › General › Storage.
  • Press Ctrl + Shift + Esc to open Task Manager, then click Performance.
  • Memory shows how much memory it has, for example 16 GB.
  • GPU shows your graphics card. If one says NVIDIA or AMD with "Dedicated GPU memory" of 8 GB or more, the model can use it and runs much faster. Most office laptops only have a built-in one (often "Intel"), which is fine but slower.
  • For disk space, open Settings › System › Storage.

Then find your computer in this table. You will choose the model in step 5.

What a smaller model changes

Everything works the same way, but a smaller model makes more mistakes, especially in deciding which tool to use. The lessons describe what happened with the standard model, so your results will differ more from them. That is still a useful way to learn: you will see first-hand why model size matters for agents.

You also need an internet connection for the downloads, and your Mac's login password (the installer asks for it once).

When it asks for a password

Type your Mac login password and press Return. Nothing appears while you type, not even dots. That is normal and on purpose: it is still receiving what you type.

Some boxes have more than one line. If Windows warns that you are pasting multiple lines, choose Paste anyway; the lines run one after another.

The setup, step by step

Tick each step as you finish it. This page remembers your ticks in this browser, so you can stop and come back.

1

Install Homebrew, the app installer

5 to 15 min

Homebrew installs the two tools this project needs. It is the standard way to install developer tools on a Mac. If you already have it, skip to step 2 (to find out, paste brew --version: if it prints a version number, you have it).

Terminal
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

It asks for your password, then says Press RETURN to continue: press Return. Your Mac may also offer to install Apple's "Command Line Tools"; say yes.

When it finishes it prints Next steps. Paste this to finish the job, so Terminal can find Homebrew:

Terminal
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

On an Intel Mac this second box is not needed: Homebrew is found automatically.

Check

Paste brew --version. It should print something like Homebrew 4.6.3.

Install Ollama, the app that runs the AI

2 to 5 min

Ollama runs the AI model on your PC, quietly in the background.

  1. Go to ollama.com/download, choose Windows and download the installer.
  2. Open the downloaded OllamaSetup.exe and click Install. If Windows asks whether to allow it to make changes, click Yes.
  3. When it finishes, Ollama starts by itself. A small llama icon appears near the clock (you may need to click the ^ arrow to see it).
2

Install Ollama and uv

1 to 3 min

Ollama runs the AI model on your Mac. uv installs Python and the tutorials' building blocks, each tutorial in its own separate space so they cannot interfere with each other or with anything else on your Mac.

Terminal
brew install ollama uv

Install uv

1 min

uv installs Python and the tutorials' building blocks, each tutorial in its own separate space so they cannot interfere with each other or with anything else on your PC. Paste this in PowerShell:

PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Then close PowerShell and open it again, so it notices the new program.

Check

In the new window, paste uv --version. It should print something like uv 0.9.5.

3

Start OllamaCheck that Ollama is running

a few seconds

This starts Ollama quietly in the background. From now on it also starts by itself whenever you log in, so you only do this once.

Terminal
brew services start ollama

The installer already started Ollama, and it starts by itself whenever you log in. If you ever quit it, open Ollama from the Start menu.

Check

Open http://localhost:11434 in your web browser. The page should say Ollama is running.

4

Download the project from GitHub

2 to 5 min

The project lives on GitHub, a website where code is shared. It is public, so you do not need a GitHub account to download it.

  1. Open github.com/jaredjavillomb/agents-framework-tutorials.
  2. Click the green Code button, then Download ZIP. The file lands in your Downloads folder.
  3. Double-click the .zip file to unzip it.Right-click the .zip file and choose Extract All, then Extract. Open the new folder: the project folder is the one inside it.
  4. Rename the project folder from agents-framework-tutorials-main to agent-frameworks. The rest of this page uses that name.
  5. In Finder, choose Go › Home and move the agent-frameworks folder there.
  6. In File Explorer, click in the address bar, type %USERPROFILE% and press Enter. That is your home folder (the one with Desktop, Documents and Downloads in it). Move the agent-frameworks folder there.

Then tell TerminalPowerShell to work inside that folder:

Terminal
cd ~/agent-frameworks

cd means "change folder", and ~ is your home folder.

Folder somewhere else?

Type cd and a space, then drag the folder from FinderFile Explorer onto the TerminalPowerShell window. Its location appears after cd. Press ReturnEnter. In the later steps, use that location wherever this page says ~/agent-frameworks.

Already use git?

Instead of the ZIP, download, name and place the folder in one go (install git first with winget install Git.Git if you need it).

Terminal
cd ~
git clone https://github.com/jaredjavillomb/agents-framework-tutorials.git agent-frameworks
cd agent-frameworks

Later, git pull inside that folder fetches any updates.

Check

Paste ls (it lists the folder). You should see names like README.md, contracts and langgraph-tutorial.

5

Download the AI model

5 to 30 min

Choose the size that fits your computer (see the table above). The commands below change to match.

The model is Qwen3, a free model from Alibaba. The last line makes a copy named qwen3-agents with fixed settings, so every tutorial uses exactly the same model; the copy takes no extra space. Paste all three lines at once; they run one after another.

Terminal
ollama pull qwen3:8b
ollama pull nomic-embed-text
ollama create qwen3-agents -f contracts/ollama/Modelfile

You will see progress bars. The last line must run from inside the agent-frameworks folder, so if you closed the window since step 4, paste cd ~/agent-frameworks first.

Check

The last line printed is success.

To change size later, choose another size here and paste the box again. It replaces the old qwen3-agents; to free the space of the old download, see Removing it all.

6

Choose a tutorial and install it

1 to 3 min each

The three tutorials teach the same lessons and build the same two agents, each with a different toolkit. Pick one to start with; the commands below change to match. You can come back and install the others later by repeating steps 6 to 8.

Terminal
cd ~/agent-frameworks/langgraph-tutorial
uv sync

uv sync downloads Python and the toolkit into this tutorial's folder only.

Check

It ends with a list of installed packages and the ready line comes back with no message in red.

7

Check that everything works

under a minute

The project comes with a checker. It tests each piece and finally asks the AI model to reply with one word.

Terminal
uv run python check_setup.py

A good result looks like this (the version numbers can differ). Every line starts with ok:

If a line says FAIL, the line under it starts with fix: and says what to do. The troubleshooting table below explains the common ones.

8

Open the lessons

a few seconds

The lessons are notebooks: pages that mix explanations with small pieces of code you can run and see the result of. They open in your web browser through an app called Jupyter.

Terminal
uv run jupyter lab notebooks/

A browser tab opens. Leave the TerminalPowerShell window open while you work; closing it stops Jupyter.

  1. In the file list on the left, double-click 00_introduction.ipynb.
  2. Each grey box is a cell. Click one and press Shift + ReturnEnter to run it and move to the next. Or use Run › Run All Cells to run the whole lesson.
  3. While a cell runs, the brackets beside it show [*]. When it finishes they show a number, and the result appears below.
  4. Cells that ask the AI something can take a minute or more, longer on a computer without a graphics card. That is normal.

When you are done for the day, choose File › Shut Down in Jupyter, then close the TerminalPowerShell window.

Coming back another day

Ollama starts by itself when you log in, so open TerminalPowerShell and paste this:

Terminal
cd ~/agent-frameworks/langgraph-tutorial
uv run jupyter lab notebooks/

The folder follows the tutorial you picked in step 6.

What is in each tutorial

All three tutorials have the same nine lessons in the same order, so you can open the same lesson in two toolkits side by side and compare. Take them in order. Along the way you build two agents: ShipFast, a customer-support helper for a made-up online shop that must ask a person before giving any refund over $100, and a research agent that answers questions from a set of articles and checks its own answer.

#LessonWhat you learn
00IntroductionWhat the toolkit is, its main idea, and a setup check
01The modelTalk to the AI model and get answers in a fixed format
02ToolsLet the AI use tools, such as looking up an order
03The agentCombine model, instructions and tools into an agent, and see how it decides when to stop
04State and memoryRemember a conversation across messages
05OrchestrationChain steps into a workflow where the AI checks its own draft
06Guardrails and approvalPause before a refund over $100 until a person says yes
07Tracing and evaluationMeasure cost and time, and score answers automatically
08CapstoneBoth agents finished and tested
Your results may differ a little

Each lesson describes what happened when we ran it with the standard model, mistakes included. A small AI model does not always give exactly the same answer, so yours may be worded differently or make a different mistake, and more so with a smaller model. That is part of what the lessons teach.

Removing it all later

To free the disk space when you are finished, paste this. It deletes the AI models of every size and stops Ollama. A model you never downloaded is reported as "not found"; that is fine.

Terminal
ollama rm qwen3-agents
ollama rm qwen3:8b
ollama rm qwen3:4b-q4_K_M
ollama rm qwen3:1.7b
ollama rm nomic-embed-text
uv cache clean

Then paste brew services stop ollama and drag the agent-frameworks folder to the Trash. To remove the tools as well, paste brew uninstall ollama uv.

Then delete the agent-frameworks folder. To remove Ollama as well, open Settings › Apps › Installed apps, find Ollama and choose Uninstall. uv is one small program and can stay.

Words you will meet

Agent
An AI model that can use tools (look up an order, search articles) and decide its next step until the job is done.
Model
The AI itself: the file that reads text and writes a reply. Here it is Qwen3, running on your computer.
8B, 4B, 1.7B
The model's size, in billions of "parameters". Bigger is smarter but needs more memory and is slower.
Ollama
The app that runs the model in the background.
TerminalPowerShell
The app where you paste commands.
Command
One line of text that tells the computer to do something, run by pressing ReturnEnter.
Homebrew
An installer for developer tools on the Mac.
uv
A tool that installs Python and each tutorial's building blocks, kept separate per tutorial.
Jupyter
The app that shows notebooks in your browser.
Notebook
A lesson file (ending in .ipynb) that mixes explanations with code you can run.
Cell
One box in a notebook. Code cells can be run; their result appears underneath.
Kernel
The engine behind a notebook that runs its code. Restarting it is like a fresh start for the lesson.
